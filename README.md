# Xwing on Stewart Platform

This is the code to control the LEGO MOC X-wing on Stewart Platform available on rebrickable.com.
A MOC that can be made entirely from the LEGO set 42100.
Instructions available **[here](https://reb.li/m/261134)**.

Check this **[video](https://youtu.be/W_uun-rZ7w0?si=wJmpXy6xAL_jfRrp)**.

**Version 1.1**
This version adds the ability to have one main platform controlling other secondary platforms.
Pybricks firmware 4.0 intruduces a different way of doing messaging, but it retains compatibility 
with version 3.6. xwplatform.py works fine with version 4.0.1.
